# 수동 대체 경로 (Manual Fallbacks)

> 외부 API가 확인되지 않거나 대행사 계약 전까지는 **앱이 운영자의 수동 작업을 보조**하는 역할만 합니다.
> 각 기능이 "자동 연동되지 않을 때 어떻게 운영자가 손으로 처리하는지"를 명시합니다.

이 문서는 [`from-gpt-to-claude` 문서 §5-1~5-2](../from%20gpt%20to%20claude.md)의
"**외부 API 미확정 영역은 TODO가 아니라 수동 운영 플로우로 작동해야 함**" 원칙을 반영합니다.

---

## 매트릭스

| 기능 | 자동화 상태 | 운영자 수동 경로 | 앱이 보조하는 것 |
|---|---|---|---|
| 네이버 예약 수집 | `manual` | 수동 입력 / (향후) CSV 임포트 | 예약 칸반 + 상태 관리 + 노쇼 감지 |
| 네이버 예약 확정 | `unavailable` | 네이버 관리자 화면에서 확정 or "즉시 확정" 설정 | 대기 목록 + 30분+ 미처리 알림 |
| 네이버 톡톡 메시지 수신 | `unknown` | 네이버 톡톡 앱/파트너센터에서 확인 | — (보류) |
| 네이버 톡톡 답변 | `unavailable` | 운영자가 네이버 톡톡에서 직접 답변 | 분류 / 템플릿 제안 / 초안 / 상태 기록 |
| 네이버 리뷰 수집 | `manual` | 텍스트 붙여넣기 / 이미지 OCR / CSV 배치 | 리뷰 인박스 + 검색/필터 |
| 네이버 리뷰 답글 등록 | `manual` | 운영자가 네이버 플레이스에서 직접 등록 | 초안 생성 → 컴플라이언스 → 승인 → "등록 완료 처리" 버튼 |
| 카카오 상담톡 | `unavailable` | 카카오 채널 관리자센터에서 직접 응대 | — (상담톡 대행사 계약 전 비활성) |
| 카카오 챗봇 FAQ | `manual` | 오픈빌더 시나리오 설정 + 앱 웹훅 URL 등록 | `/api/webhooks/kakao/chatbot` 엔드포인트 + 템플릿 응답 |
| 카카오 알림톡/친구톡 | `unavailable` | 대행사 콘솔에서 직접 발송 | — (계약 + 템플릿 심사 필요) |
| 노쇼 위험 감지 | `supported` (앱 내부) | — | 20분+ 경과 자동 감지 + 배너 + (향후)알림톡 |
| 답글 컴플라이언스 | `supported` (앱 내부) | — | 키워드 1차 + LLM 의도 2차 이중검사 |

---

## 상태 정의

| 상태 | 의미 | UI 표시 |
|---|---|---|
| `supported` | 공식 API/상품으로 확인, 앱이 자동 처리 | 녹색 배지 "지원" |
| `manual` | 외부 조작은 운영자 수동, 앱은 UI/기록 제공 | 노란 배지 "수동" |
| `unknown` | 공식 문서 미확인, 추가 조사 필요 | 회색 배지 "미확인" |
| `unavailable` | 공식적으로 불가 / 대행사·딜러사 계약 필수 | 빨간 배지 "불가/계약필요" |

## 흐름별 수동 대체 상세

### 리뷰 답글 (가장 자주 쓰는 흐름)
```
새 네이버 리뷰 올라옴
  ↓ 운영자가 본다
앱 /reviews 에서 "새 리뷰" 추가 (텍스트 붙여넣기 or 이미지 업로드)
  ↓
"초안 생성" — GPT 또는 결정형 엔진이 답글 작성
  ↓
"컴플라이언스 검사" — 키워드 + LLM 의도 이중검사
  ↓
운영자 검토 → 수정 → "승인"
  ↓
승인된 답글을 복사 → 네이버 플레이스에 직접 붙여넣기 등록  ★수동★
  ↓
앱으로 돌아와 "등록 완료 처리" 클릭
  ↓
상태 posted, 감사 로그 기록
```

### 상담 응대 (현재)
```
카카오채널/네이버톡톡에 문의 옴
  ↓ (향후) 웹훅 or 운영자가 본다
앱 /conversations 에 수동 카드 생성 (현재는 mock, 향후 웹훅 연결)
  ↓
"자동 분류" — 11 카테고리 + 위험도 판정
  ↓
민감 키워드 감지 시 자동 "검토 필요" 전환
  ↓
운영자가 카카오채널/네이버톡톡에서 직접 응대  ★수동★
  ↓
앱에서 상태 → "완료" 로 변경
```

### 예약 확정
```
네이버 예약에 새 예약 들어옴
  ↓ 운영자가 네이버 앱 알림으로 본다
[방법 A] 네이버 예약을 "즉시 확정"으로 설정 → 자동 확정
[방법 B] 네이버 관리자 화면에서 수동 확정
  ↓
앱 /reservations 에 "수동 예약 추가" 버튼으로 동일 정보 입력  ★수동★
  ↓
이후 앱이 자동 감지:
  - 20분 경과 시 "노쇼 위험" 배너 + (향후) 관리자 알림톡
  - 상태별 칸반 관리
  - 감사 로그
```

### 알림톡 발송 (향후)
```
예약 확정 / 리마인드 발송 필요
  ↓ (대행사 계약 전)
앱이 템플릿 초안만 보관 + "발송 대기" 표시
  ↓
운영자가 대행사 콘솔에서 직접 발송  ★수동★
  ↓
앱에서 "발송 완료" 체크
  ↓ (대행사 계약 후)
앱이 자동 발송 + 결과 받아 상태 업데이트
```

## 언제 이 fallbacks 가 없어지나

각 채널의 자동화 상태는 `/settings/integrations` 에서 실시간 확인 가능.
`supported` 로 승격되는 시점:

- **카카오 챗봇 FAQ** → 카카오 i 오픈빌더 계정 + 웹훅 URL 등록 → `supported`
- **카카오 알림톡** → 대행사 계약 + 템플릿 승인 → `supported`
- **카카오 상담톡** → 상담톡 대행사 계약 → `supported`
- **네이버 예약/리뷰** → 공식 Partner API 확인 시 → `supported`
- **네이버 톡톡** → 공식 양방향 API 확인 시 → `supported`, 그 전까지 `unknown`

각 전환 시 `packages/providers/src/mock/mockProvider.ts` 의 해당 provider 의
`capability` 만 업데이트하면 UI/로직이 자동 반영됩니다.
